Ad Astra Web Clipper

Chrome extension for clipping articles to Ad Astra.

Ad Astra Web Clipper extracts the current article and saves it to your own Ad Astra service.

GitHub release 1.5.16

Cleaner article endings, improved Economist image capture, and removal of audio prompts and trailing subscriber promotions.

Release notes / 发布说明

Download GitHub build 1.5.16 / 下载 GitHub 版

Extract the ZIP, open Chrome Extensions, enable Developer mode, and choose Load unpacked. The GitHub build includes enhanced publisher compatibility activated after Ad Astra login; access is not guaranteed for every article.

Prefer the standard build? Install from Chrome Web Store. The Store build does not include the enhanced publisher engine.

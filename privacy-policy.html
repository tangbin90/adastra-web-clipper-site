Ad Astra Web Clipper

Privacy Policy

Last updated: 2026-08-16

Ad Astra Web Clipper is a Chrome extension for extracting the current web article and saving it to an Ad Astra service controlled by the user or organization.

Data Processed

The extension may process the current page URL, page title, article text, selected text, sync history, Ad Astra address, Ad Astra username, and Ad Astra password.

The Ad Astra password is used only to sign in to the configured Ad Astra service. It is not saved by the extension.

When AI-assisted article cleanup is enabled and normal extraction is uncertain, selected article blocks may be sent to the configured Ad Astra service for cleanup. The Ad Astra service may process those blocks through its configured AI provider. Token usage is charged to the user's Ad Astra account. The user can disable AI-assisted cleanup in the extension settings before syncing.

Data Storage

Settings and sync history are stored locally in Chrome extension storage. Some settings may use Chrome sync storage so they can follow the same Chrome profile.

When the user syncs an article, the article content is sent to the configured Ad Astra service, currently defaulting to https://www.catsdogs.site:8443.

Data Sharing

The extension does not sell user data, use user data for advertising, or share user data with third-party analytics providers.

The extension sends article data only to the Ad Astra service configured in the extension. The extension does not contact an AI provider directly. When AI-assisted cleanup is enabled, the configured Ad Astra service may use its configured AI provider to process selected article blocks under the service's configuration and privacy terms.

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

The extension requests access to the default Ad Astra host so it can log in and save articles.

For other websites, the extension uses active tab access or asks Chrome for site access only when the user starts a sync action for that site.

Contact

For privacy questions, contact the extension publisher through the support contact listed on the Chrome Web Store page.
